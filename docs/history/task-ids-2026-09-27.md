# Task IDs renumbered (2026-09-27)

The owner, 2026-09-27: `docs/todo.md`'s IDs changed from a letter and a number (`R1`) to an area word and
a number (`RELEASE-1`), so a person can tell from the ID what a task is about. Each section was numbered
again from 1, in the order its rows stood. The letters were: R = RELEASE, C = CONSOLE, H = HWTEST (hardware
proofs), K = KERNEL, E = EMU (emulators and RetroArch), X = TOOLS (console and PC tools), S = SDK
(extensions, the Store, processors), A = APPS, P = PLATFORM (the other platforms), D = DOCS.

Commits, `docs/history/`, `docs/archive/`, the teams' notes and the other repositories keep the old IDs;
this table is how to find the row they mean. An old ID missing here had no row left on 2026-09-27 (its
row was deleted when the work was done).
